# Project Overview

This project presents an interactive Financial Dashboard developed using Microsoft Power BI to analyze customer income, revenue, transactions, and demographic information.
The dashboard provides meaningful financial insights through interactive visualizations, KPIs, charts, and filters to support data-driven decision-making.

## Project Objectives

- Analyze total revenue, income, and transaction amounts.
- Understand customer demographics and age groups.
- Identify revenue distribution across different states.
- Analyze customer job categories and educational levels.
- Explore financial patterns based on gender and marital status.

## Key Performance Indicators (KPIs)

- Total Revenue: 55.3M
- Total Interest Earned: 7.8M
- Total Income: 576M
- Average CSS: 3.2

## Dashboard Features

- Revenue and income analysis.
- Income by age group.
- Total income by state.
- Customer job and education analysis.
- Marital status and gender distribution.
- Dependent count by age group.
- Card category analysis by education level.
- Geographic customer distribution using a map.
- Interactive filters for Week Start Date, card category, gender, quarter, and credit category.

## Key Insights

- Total income is approximately 576M.
- The 40–50 age group contributes the highest income.
- New York, Texas, and California are among the top states by income.
- Businessmen contribute the highest income among customer job categories.
- Graduate customers represent the largest education category.
